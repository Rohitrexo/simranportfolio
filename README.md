# Simran Rawat Portfolio

Responsive portfolio website for Simran Rawat. Built as a static site for GitHub Pages or Vercel deployment.

## Structure
- `index.html` — portfolio markup
- `styles.css` — responsive styling
- `script.js` — interactions and animations
- `assets/` — portrait, case-study images and professional CV

## Deploy on Vercel
Import this repository into Vercel and deploy as a static site. No build command is required.
