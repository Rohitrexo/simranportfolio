# Simran Rawat Portfolio

A responsive, static portfolio website for Simran Rawat.

## Structure
- `index.html` — all page content and sections
- `styles.css` — responsive visual system and animation
- `script.js` — tabs, industry-word animation, ticker logos and cursor glow
- `assets/simran-rawat.png` — supplied portrait
- `assets/masala-mandala.png` — supplied Instagram screenshot
- `assets/dakshis.png` — supplied Instagram screenshot
- `assets/zoff.png` — supplied LinkedIn screenshot
- `assets/har-ghar-tiranga.png` — supplied campaign screenshot
- `assets/Simran-Rawat-CV.pdf` — supplied CV, embedded and downloadable

## Deploy to Vercel
1. Push the folder to GitHub.
2. Import the repository into Vercel.
3. Framework preset: **Other** (or leave auto-detect).
4. Build command: none.
5. Output directory: `.`
6. Deploy.

The brand ticker uses Google favicon fetching at runtime for brand marks. If you want a fully offline/self-contained build, replace those runtime favicon URLs with local SVG/PNG logo assets.
